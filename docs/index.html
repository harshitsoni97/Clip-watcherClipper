Wasted Weekly Uploader

Wasted Weekly Uploader is a private, single-user tool that publishes edited gaming highlight videos to the Wasted Weekly YouTube channel. It is operated solely by the channel owner and is not offered to the public.

What it does

  • Selects popular moments from public Twitch clips by permitted, credited streamers.
  • Edits them into ranked highlight videos and Shorts with original commentary.
  • Uploads the finished videos to the owner's own YouTube channel using the YouTube Data API (scope: youtube.upload).
