Privacy Policy

Last updated: November 16, 2026

Wasted Weekly Uploader ("the app") is a private tool used only by the owner of the Wasted Weekly YouTube channel.

Google user data the app accesses

The app requests a single permission, https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the authorizing account's YouTube channel. It does not read, collect or store any other Google user data, such as email, contacts, viewing history or channel analytics.

How the data is used and stored

  • The OAuth token is stored only on the owner's own machine, so that scheduled uploads can run. It is never transmitted to any server other than Google's.
  • No Google user data is sold, shared with third parties, or used for advertising or for training AI models.

YouTube

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the stored token file on the owner's machine also removes the app's access.
